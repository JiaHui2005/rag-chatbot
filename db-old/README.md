# Database Directory
Thư mục này dùng để lưu trữ cơ sở dữ liệu Vector (Vector Database).

### Chi tiết:
- Mặc định sử dụng **ChromaDB**.
- Dữ liệu được lưu dưới dạng các vector nhúng (embeddings) sau khi đã xử lý từ thư mục `data/`.

*Lưu ý: Thư mục này thường được cấu hình trong `.gitignore` để tránh đẩy dữ liệu local lên server.*
